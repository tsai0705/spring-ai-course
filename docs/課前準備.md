# Spring AI 入門實作課：課前準備

這份文件帶你在上課前把環境裝好。請在網路穩定時完成，模型檔案很大，下載需要時間。

## 1. 安裝 JDK 21 以上

1. 到 https://adoptium.net/ 下載 Temurin JDK 21（或更新的 LTS 版本）。
2. 執行安裝程式，Windows 安裝時勾選「Set JAVA_HOME variable」與「Add to PATH」。
3. 安裝完成後，關掉並重新開啟終端機（PowerShell），再繼續。

## 2. 安裝 IntelliJ IDEA

到 https://www.jetbrains.com/idea/download/ 下載並安裝 IntelliJ IDEA，不需要付費訂閱就能使用。

## 3. 安裝 Ollama

1. 到 https://ollama.com/download 下載並安裝，安裝後 Ollama 會在背景執行（預設 `http://localhost:11434`）。
2. 開啟 PowerShell，下載兩個模型（約數 GB，請在網路穩定時下載）：

```bash
ollama pull qwen2.5:3b
ollama pull nomic-embed-text
```

## 4. 取得專案

專案網址：https://github.com/tsai0705/spring-ai-course

在專案頁面按綠色的 **Code** 按鈕，選 **Download ZIP**，下載後解壓縮。會用 git 的話也可以直接 clone：

```powershell
git clone https://github.com/tsai0705/spring-ai-course.git
```

接著用 IntelliJ 的 File > Open 開啟專案資料夾。

## 5. 編譯一次

在專案根目錄開啟 PowerShell，第一次會下載相依套件，需要幾分鐘：

```bash
.\mvnw.cmd compile
```

macOS/Linux 改用 `./mvnw compile`。

## 6. 確認準備完成

| 檢查指令 | 預期結果 |
|---|---|
| `java -version` | 顯示版本 21 以上 |
| `ollama list` | 清單裡有 `qwen2.5:3b` 與 `nomic-embed-text` |
| `ollama run qwen2.5:3b "你好"` | 模型回覆一段文字 |
| `.\mvnw.cmd compile` | 最後顯示 `BUILD SUCCESS` |

四項都符合，就準備好了。

## 卡住怎麼辦

- `java -version` 顯示舊版本或找不到指令：重新開啟終端機；還是不行就檢查 JDK 是否安裝成功，並確認環境變數 `JAVA_HOME` 指向 JDK 21 的資料夾。
- `ollama` 指令找不到，或 `ollama list` 連不上服務：重新開啟終端機，確認 Ollama 已經在背景執行（工作列右下角的系統匣有 Ollama 圖示），沒有的話從開始選單打開它。
- `.\mvnw.cmd compile` 失敗：先確認 `java -version` 是 21 以上，並且人在專案根目錄（有 `pom.xml` 的資料夾）。仍然失敗就把完整錯誤訊息截圖給講師。
