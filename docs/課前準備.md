# Spring AI 入門實作課：課前準備

這份文件帶你在上課前把環境準備好。請在網路穩定時完成，下載相依套件需要時間。

## 版本確認

全部符合就準備完成了；哪一項不符合或沒有安裝，再看下面對應的章節。

| 檢查項目 | 指令（PowerShell） | 合格標準 | 不符合請看 |
|---|---|---|---|
| JDK | `java -version` | 版本 21 以上 | 第 1 節 |
| Node.js | `node -v` | v18 以上 | 第 2 節 |
| npx | `npx -v` | 有印出版本號 | 第 2 節（npx 隨 Node.js 一起安裝） |
| IntelliJ IDEA | 打開 IntelliJ | 能正常開啟並開啟專案 | 第 3 節 |
| Gemini API key | `echo $env:GEMINI_API_KEY` | 印出你的 key | 第 4 節（申請 key 與設定環境變數） |
| 專案編譯 | `.\mvnw.cmd compile`（在專案資料夾內執行） | 最後顯示 `BUILD SUCCESS` | 第 5 節（取得專案） |

macOS/Linux 的差異：編譯指令用 `./mvnw compile`，查看 key 用 `echo $GEMINI_API_KEY`。

## 1. 安裝 JDK 21 以上

1. 到 https://adoptium.net/ 下載 Temurin JDK 21（或更新的 LTS 版本）。
2. 執行安裝程式，Windows 安裝時勾選「Set JAVA_HOME variable」與「Add to PATH」。
3. 安裝完成後，關掉並重新開啟終端機（PowerShell），再執行 `java -version` 確認。

## 2. 安裝 Node.js 18 以上

課程之後會用 `npx` 啟動 MCP Server，所以需要 Node.js 18 以上，`npx` 會隨 Node.js 一起安裝。第一次執行 `npx` 啟動 MCP Server 時會下載套件，需要連網，會比較久。

1. 到 https://nodejs.org/ 下載 LTS 版本並安裝。
2. 安裝完成後，重新開啟 PowerShell，再執行 `node -v` 與 `npx -v` 確認。
3. 預先下載 MCP Server：在任一資料夾開啟 PowerShell，執行下面的指令：

```powershell
npx -y @modelcontextprotocol/server-filesystem .
```

   第一次會下載套件。看到 `Secure MCP Filesystem Server running on stdio` 這行訊息後，按 `Ctrl+C` 結束。套件已經快取，上課第一次啟動就不會因為下載太久而逾時。

## 3. 安裝 IntelliJ IDEA

到 https://www.jetbrains.com/idea/download/ 下載並安裝 IntelliJ IDEA，不需要付費訂閱就能使用。

## 4. 申請 Gemini API key 並設定環境變數

課程的聊天模型使用 Google Gemini，需要一組 API key。

1. 到 https://aistudio.google.com/ ，用你的 Google 帳號登入。
2. 在 Google AI Studio 裡建立並取得 API key（有免費額度）。
3. 把 key 複製起來，接著設定環境變數。

每個人請用**自己的 Google 帳號**申請，不要共用 key。免費額度以專案為單位計算：好幾個人共用同一把 key，或在同一個專案裡開多把 key，都會搶同一份額度，上課時很容易看到 429 錯誤。

注意：API key 等於你的密碼，不要貼到程式碼裡，也不要上傳到 GitHub。

專案會從環境變數 `GEMINI_API_KEY` 讀取 key。

Windows（PowerShell）：

```powershell
setx GEMINI_API_KEY "你的key"
```

設定後要**重新開啟 PowerShell 和 IntelliJ** 才會生效。

macOS/Linux：

```bash
export GEMINI_API_KEY="你的key"
```

這一行只對目前的終端機有效；想永久生效，就寫進 `~/.zshrc` 或 `~/.bashrc`。

## 5. 取得專案並編譯

專案網址：https://github.com/tsai0705/spring-ai-course

在專案頁面按綠色的 **Code** 按鈕，選 **Download ZIP**，下載後解壓縮。會用 git 的話也可以直接 clone：

```powershell
git clone https://github.com/tsai0705/spring-ai-course.git
```

接著用 IntelliJ 的 File > Open 開啟專案資料夾。

在專案根目錄開啟 PowerShell，編譯一次。第一次會下載相依套件，需要幾分鐘：

```powershell
.\mvnw.cmd compile
```

macOS/Linux 改用 `./mvnw compile`。

## 卡住怎麼辦

- `java -version` 顯示舊版本或找不到指令：重新開啟終端機；還是不行就檢查 JDK 是否安裝成功，並確認環境變數 `JAVA_HOME` 指向 JDK 21 的資料夾。
- `node` 或 `npx` 找不到：重新開啟 PowerShell 與 IntelliJ；仍不行就重新安裝 Node.js，並確認安裝時有加入 PATH。
- `.\mvnw.cmd compile` 失敗：先確認 `java -version` 是 21 以上，並且人在專案根目錄（有 `pom.xml` 的資料夾）。仍然失敗就把完整錯誤訊息截圖給講師。
- 啟動時出現 API key 相關錯誤：確認 `echo $env:GEMINI_API_KEY` 有印出 key，沒有的話重新執行 `setx`；已經設定過就把 IntelliJ 完全關掉再重開。
